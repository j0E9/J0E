# Joe Paul K — GitHub Pages portfolio

## Files
Keep these three files in the repository root:

- `index.html`
- `styles.css`
- `Setup.png` (your separate background photograph)

The photograph is **not embedded** in the HTML or CSS. The CSS references it as `./Setup.png`, while all text and effects are separate foreground elements.

## Publish with GitHub Pages
1. Open the repository → **Settings** → **Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`.
4. Click **Save**.
5. Wait for the deployment to finish. The project site URL should be:
   `https://j0E9.github.io/JOE/`

GitHub Pages documentation:
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Customize
- Replace the LinkedIn `href="#"` in `index.html` with your real LinkedIn URL.
- Replace `hello@example.com` with the email address you want public.
- Adjust image framing in `styles.css` with `background-position`.
